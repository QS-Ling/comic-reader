# 漫画阅读器（静漫）

面向 Android 7.0 及以上，支持包子漫画与奇漫屋两个来源。采用“发现 / 书架 / 我的”底部导航：发现页提供搜索和推荐频道，书架集中显示收藏与最近阅读，来源、缓存、外观和链接工具放在“我的”。推荐书目以三列封面网格显示，每页 12 部、四行，长名称最多两行并省略；点击打开目录，长按显示完整名称、简介和封面预览。详情页使用封面、简介、章节目录与底部固定阅读按钮。支持上下话、阅读位置保存及浅色/深色模式，无需账号。

应用从游客 HTML 提取书目、目录及公开图片地址，使用原生界面和自建阅读页面。包子来源遇到 Cloudflare 403 时提供正常的访客验证窗口，通过后自动返回；该窗口仅允许页面文档和 Cloudflare 验证资源，阻止广告资源、账号路径和 App 脚本，不添加原生 JavaScript 桥接。普通请求最多携带 Cloudflare 访客验证 Cookie，不接入账号或设备标识。正文仅运行打包脚本和允许列表内图片请求。目录和章节数据需联网，已保存图片优先读取本地。

没有引入原包中的广告 SDK、LIAPP、SO 库或账号功能。安装清单只有 INTERNET 权限。书架和进度保存在静漫私有数据中，同签名升级保留，卸载会删除；不与原版账号云端书架同步。

## 图源与本地检索说明

- 奇漫屋：[https://www.qimanwu.app/](https://www.qimanwu.app/)
- 包子漫画：[https://www.baozimh.com/](https://www.baozimh.com/)，应用使用的公开页面入口为 [https://appcn.baozimh.com/baozimhapp/homepage](https://appcn.baozimh.com/baozimhapp/homepage)。

奇漫屋漫画检索使用本地保存的书目索引，随应用内置书名、详情链接和封面地址，并可通过“我的 → 奇漫屋本地书目”继续更新。本地保存的是用于搜索的书目信息，并非全部漫画正文；目录和未缓存的章节图片仍需联网读取图源。

**能够搜到不代表一定能够阅读。** 本地索引可能保留已经下架、链接或图片失效、暂时受到访问限制的漫画，因此部分检索结果可能无法打开目录或阅读章节。索引也可能尚未收录源站新增作品。实际可读情况以图源当前提供的内容和访问状态为准。

## 安装

从 [GitHub Releases](https://github.com/QS-Ling/comic-reader/releases) 下载 `jingman-0.4.10.apk`，传到安卓手机，打开文件并允许对应文件管理器安装应用。这是本地测试签名的个人试用版本，可覆盖安装旧版静漫，保留进度、书架和章节缓存；与原版包子漫画是两个独立应用。

0.4.10 修复奇漫屋部分章节浏览器可看、应用图片404的问题。保留官网图片代理地址，原图直连明确404/410时回退到官网代理；仅代理请求携带经过校验的本站章节来源地址，原图直连仍不带Referer/Origin。同话后续图片复用成功路线，代理图片也写入既有章节缓存。图片入口均失效时才有限尝试同名章节的备用入口，成功入口记住；不因403/429或普通网络超时自动切换入口。第14话不同副标题仍保留，不能仅凭话号视为同一章节。

0.4.9 修复奇漫屋同一话重复显示：按完整章节名合并不同链接，默认使用目录后列出的替换入口；不同副标题仍分别保留。原链接保留为备用入口，可在阅读页“更多 → 切换本话入口”选择。旧阅读进度按链接别名定位到合并后的章节，原章节图片缓存不删除。实测《财富自由后，她们献上了忠诚》第1话旧入口首图404、替换入口首图200；合并后157个链接显示107条。源站普通403仍可能独立发生。

0.4.8 奇漫屋首页先显示本机保存内容，仅在冷启动进入首页时同步一次，之后由下拉或刷新按钮手动同步；返回首页、切换底部导航及重建界面不自动同步。同步进行中合并重复操作，403/429 后遵守一分钟后台冷却，不自动重试。成功才原子替换首页快照，失败保留书目并显示保存时间和失败提示；首次安装内置本次实际官网首页的 62 部书目，独立于全量搜索索引。首页缺失封面不再触发额外目录补取。此改动减少请求并保留可浏览内容，不能保证消除源站对应用请求的 403。

0.4.7 根据小米真机复测调整奇漫屋访问：使用官网支持的 pc=1 页面模式，统一为当前手机浏览器引擎版本的移动请求标识，详情封面使用相同标识；章节文档携带对应漫画目录的站内来源地址，正文图片仍保持独立无来源头请求。明确区分带验证资源的挑战与 OpenResty 普通 403，普通拒绝不自动弹验证码；验证页发生错误时保留窗口和错误信息。后台话数改为单路、请求至少间隔 1.5 秒，继续保留缓存、限流和重复请求合并。网址输入采用 URI 模式，避免输入法改写；支持显式 ACTION_VIEW 打开受支持漫画链接以便复现。真机已验证目标漫画 100 话、第1/2集与正文图片，Wi-Fi 恢复后新进程也取得 200。源站曾在同一时段间歇拒绝普通浏览器和应用请求，具体站点访问规则无法从 403 单独确定，不能承诺消除所有源站拒绝。

0.4.6 针对奇漫屋目录 403 增加可见的标准访客验证，正常请求复用同一桌面 User-Agent 及仅限 Cloudflare 访客验证的 Cookie。验证文档仅允许两个来源的受支持公开页面和 Cloudflare 验证资源，不添加 JavaScript 桥接，不接入账号。话数、封面解析和扫描等后台请求不弹验证，遇到 403/429 暂停后台请求一分钟；用户主动打开目录时才可验证。奇漫屋成功 HTML 缓存两分钟、最多 24 页并限制总字符量，同地址并发合并，避免刚查完话数又重复下载目录；错误或验证未完成的页面不缓存。拒绝跳转到站外或账号页面，区分无验证可完成的明确拒绝，不再空等超时。错误页显示具体原因。

0.4.5 搜索栏新增“当前源／双源”范围选择并记住偏好。双源模式并行读取奇漫屋本地书目和包子在线搜索，结果交错展示；同名作品保留两个来源的版本，显示各源及已加载合计数量。包子结果支持继续加载和失败重试，一个来源失败不会清空另一个来源的结果。单源和双源搜索卡片均显示来源与总话数。仅为可见卡片读取详情页，最多两个并发，成功话数按漫画链接缓存两小时、最多 256 本；离线或失败时显示未获取，可点按重试。话数按目录唯一可阅读章节统计，包含隐藏章节，排除相关推荐。打开目录或详情预览会刷新话数。

0.4.4 扫描奇漫屋官网公开分类、漫画类型、连载状态、标签与排序分页，本次遍历 109 个入口、2,305 页，去重后将 13,645 部书目内置到应用。奇漫屋搜索直接查询本地索引，不再等待官网搜索接口，支持离线查书名；目录和正文仍需联网。“我的 → 奇漫屋本地书目”可查看数量、开始或继续扫描；搜索页也可更新书目。手机扫描逐页读取官网，保存书名、详情链接和封面地址，不下载正文或封面文件。每十页及暂停/失败时原子保存索引和待扫描队列，成功页不重复读取，失败页不阻塞其他分类，下次更新可重试。遍历范围是官网公开分类可发现的书目，不能保证包含未公开或未归类的作品。修正“我的”页面版本号，改为读取实际安装版本。

0.4.3 修复奇漫屋搜索关键词和来源隔离，采用官网的 `/index.php/search?key=` 入口。官网搜索为空或请求失败时，使用随包收录的官网首页与分类书目索引（本次 528 部）及已浏览奇漫屋书目匹配，不再混入包子来源。明确显示索引匹配范围，搜索页可点“更新书目”从官网首页和分类分页重新建立索引；显示进度，切换页面可取消，失败保留已有索引。该索引不是完整书库，未收录作品仍可能搜不到。章节目录支持正序／逆序切换并记住偏好，仅改变显示顺序，不改变章节路径、继续阅读或上一话／下一话顺序。

## 构建

本机可运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`，或用参数 `-Sdk`、`-Jdk` 指定 Android SDK 和 JDK。需要 SDK Platform 34、Build Tools 34.0.0 和 JDK。也可使用 Android Studio 打开 Gradle 项目。

## 依赖与限制

`app/src/main/assets` 的 jquery.js、crypto.js、pic.js 来自原网站公开阅读页使用的资源，保留原有文件头。pic.js 为原站阅读兼容脚本快照，增加了一处图片 URL 映射调用。早期测试中图片代理在未带章节来源头时返回 403，曾仅使用原图直连；0.4.10 已实测同一图片直连404而官网代理在携带章节来源头时200，现按直连与官网代理回退加载。其余地址保留原有逻辑，并受请求允许列表限制。网站更改数据格式、图片域名或加载规则时可能需要更新适配。

目录和章节网络请求在工作线程执行；阅读历史仅保存在设备应用数据中。没有添加原生 JavaScript 桥接接口，不忽略 TLS 证书错误。夜间模式调整界面背景，不修改漫画原图。

验证方法见 `VERIFICATION.md`。电脑端构建和脚本检查不等同于安卓真机验证。
